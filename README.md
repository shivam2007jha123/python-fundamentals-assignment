# Python Fundamentals Assignment

This repository contains my Python programming assignment covering important fundamental concepts.

## Topics Covered

* Conditional Statements — `if`, `elif`, `else`
* Loops — `for`, `while`
* Functions
* Scope of Variables
* Modules and Packages

## Tasks

### Task 1 — Conditional Statements

A program that takes a student's marks as input and displays the appropriate grade using `if`, `elif`, and `else`.

**Grading System:**

* 90–100 → A+
* 80–89 → A
* 70–79 → B
* 60–69 → C
* 50–59 → D
* Below 50 → Fail

Invalid marks are also handled.

### Task 2 — Loops & Number Patterns

A program that:

* Prints numbers from 1 to N using a `for` loop.
* Prints numbers from N to 1 using a `while` loop.
* Displays the multiplication table of the given number.

### Task 3 — Functions

A calculator program using separate functions for:

* Addition
* Subtraction
* Multiplication
* Division
* Modulus

### Task 4 — Scope of Variables

A program demonstrating:

* Local variables
* Global variables

It also explains the difference between variables defined inside and outside a function.

### Task 5 — Modules & Packages

A program demonstrating useful operations from Python's built-in modules:

* `math` — calculating square root
* `random` — generating random numbers
* `datetime` — displaying the current date and time

## Technologies Used

* Python 3
* VS Code

## Purpose

The purpose of this assignment is to practice and strengthen the fundamental concepts of Python programming through practical programs.
